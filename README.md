# Outline Studio

투명 PNG/WEBP의 외곽선을 편집하고 화이트·칼선을 인쇄용 별색 PDF로 내보내는 브라우저 전용 도구입니다. 이미지 처리와 파일 생성은 기기 안에서만 이루어지며, 업로드 서버·CDN·분석 도구를 사용하지 않습니다.

## 사용 방법

화면은 5단계로 나뉘며, 현재 단계에 필요한 UI만 표시됩니다. 상단 단계 표시(01~05)로 이동할 수 있고, 아직 조건이 충족되지 않은 단계는 잠깁니다.

1. **01 이미지 입력** — 투명 배경 PNG/WEBP를 선택합니다. 파일을 선택하면 02단계로 이동합니다.
2. **02 규칙 설정** — 외곽 여유, 최종 높이, 목 보강 웹, gap-fill, 센터탭 상세값을 확인하고 **파이프라인 실행**을 누릅니다. 실행이 끝나면 03단계로 이동합니다.
3. **03 외곽 편집** — 브러시/지우개로 최종 칼선을 다듬고, 연결 성분·내부 홀·크기를 확인합니다. Ctrl/Cmd+Z로 되돌릴 수 있습니다.
4. **04 화이트 · 스팟** — 화이트 스와치(`rdg_white`, `white`, `spot_0`, 직접 입력)와 칼선 스와치 이름을 지정합니다. 기본 칼선 이름은 `CutContour`이며, 이 단계에서는 화이트 영역이 항상 표시됩니다.
5. **05 내보내기** — 파일명을 입력하고 **PDF · 인쇄 스팟**, SVG, PNG, 검사 JSON을 내려받습니다. 같은 파일명이 모든 형식에 적용됩니다.

02단계에서 설정을 바꾸면 결과를 자동으로 다시 계산하고 03단계로 이동합니다. 이때 브러시로 직접 수정한 내용은 초기화되며, 상태 줄에 그 사실이 표시됩니다. 같은 이미지로 다시 계산할 때는 02단계의 **다시 실행** 버튼을 사용합니다.

## 화이트 생성

- 크기 조정된 입력 이미지의 알파 임계값과 **작은 조각 제거** 설정을 사용합니다. 기본값은 알파 8 초과, 아일랜드 1 mm² 미만 제거입니다. 원본 이미지를 색상 자체에서 지우는 것은 아닙니다.
- 알파의 투명한 내부 홀은 채우지 않습니다. 정리된 알파 경계를 벡터로 추출하고 모든 바깥 경계와 내부 홀 경계에 0.15 mm 안쪽 침식을 적용합니다. 오프셋은 화면 픽셀에 반올림하지 않고 서브픽셀 벡터 좌표에서 계산합니다. 입력 알파 경계 자체는 약 300 dpi의 래스터를 기반으로 합니다.
- 매우 얇은 부분은 침식 후 사라질 수 있습니다. 화이트 영역이 완전히 없어지면 PDF 내보내기가 중단됩니다.
- 화이트는 원본 알파에서 생성되므로 브러시로 칼선을 수정해도 화이트 모양이 자동으로 바뀌지 않습니다. 둘의 위치 관계를 검토하세요.

## PDF 인쇄 및 확인

- PDF에는 원본 RGB 이미지(알파 포함), 화이트 벡터 면, 칼선 벡터가 포함됩니다. 화이트와 칼선은 지정한 이름의 독립적인 PDF `/Separation` **별색 분판**이며, 둘 다 오버프린트로 설정됩니다. 칼선 폭은 0.2 mm입니다. 각 요소는 별도 PDF 레이어에도 들어갑니다.
- 별색 이름은 RIP/프린터에 설정된 이름과 대소문자까지 일치해야 합니다. 입력은 영문·숫자·일반 ASCII 기호로 제한하며 PDF 예약 색상명(`All`, `None`, `Cyan`, `Magenta`, `Yellow`, `Black`)과 중복된 화이트/칼선 이름은 허용하지 않습니다.
- 오버프린트를 지원하지 않는 일반 PDF 뷰어에서는 화이트가 이미지를 가릴 수 있습니다. **Acrobat 출력 미리보기의 오버프린트** 또는 RIP 분판 미리보기로 화이트와 칼선을 각각 확인하세요. PNG는 일반 화면용 미리보기입니다.
- PDF 페이지의 시각적 객체 순서가 실제 잉크 인쇄 순서를 결정하지는 않습니다. RIP에서 화이트 스팟을 해당 흰색 잉크에 매핑하고 화이트 인쇄 순서를 확인해야 합니다.
- 원본 아트는 RGB로 유지하며 출력 ICC 프로필이나 PDF/X 인증은 포함하지 않습니다. 인쇄소가 지정한 색상 프로필, 스팟 이름, 화이트 인쇄 순서 및 실제 장비의 결과를 사전에 확인하세요.
- SVG는 이미지와 화이트·칼선 벡터 및 스팟 이름 메타데이터를 포함하지만 **실제 별색 분판은 아닙니다**. 인쇄 별색에는 PDF를 사용하세요.

## 칼선 파이프라인

1. 투명 영역을 자르고 알파를 기준으로 작은 성분을 제거합니다. 화이트는 이 단계에서 별도 생성합니다.
2. 칼선 실루엣의 내부 홀을 채우고 기본 2 mm 바깥 오프셋과 기본 10 mm 목 보강 웹을 적용합니다.
3. 오프셋과 목 보강을 마친 아웃라인을 기준으로 스캐폴드를 만들고, 아래의 Boolean 조각 선별을 수행합니다. 이후 국소 gap-fill, 접합부와 센터탭을 만들고 연결 성분을 검사합니다.
4. 브러시/지우개로 최종 이진 칼선 마스크를 편집하고 연결 성분·홀·크기를 확인할 수 있습니다.

### 중앙 스캐폴드 자동 형상

`W`는 오프셋·목 보강 후, 스캐폴드와 탭을 합치기 전 본품 아웃라인의 전체 가로폭입니다.

| 아웃라인 폭 W | 스캐폴드 후보 |
| --- | --- |
| W < 50 mm | 둥근 정삼각형. 둥글리기 전 한 변 50mm, 세 꼭짓점 R1mm. |
| W ≥ 50 mm | 둥근 사각형. 폭 50mm, 높이는 본품 전체 아웃라인 높이, 모서리 R1mm. |

정삼각형은 꼭짓점이 위로 향하고 기준 밑변이 본품 하단에 맞도록 위치합니다. 50mm는 꼭짓점을 둥글리기 전 정삼각형의 변입니다. R1mm를 적용한 삼각형 단독 형상의 이론상 최대 폭은 약 48.54mm, 높이는 약 42.30mm이며, 남은 직선 변은 약 46.54mm입니다. 본품이 좁을 때 스캐폴드가 본품보다 넓을 수 있습니다.

본품 실루엣을 보존하고 스캐폴드에서 본품 바깥인 조각만 분리합니다. 상단 1/3에 닿는 조각은 전체를 제외하고 나머지를 합칩니다. 본품 형상에 따라 일부 또는 모든 스캐폴드 조각이 제외될 수 있으며 합칠 조각이 없으면 `검토 필요`로 표시합니다. 이후 gap-fill, 국소 접합 다듬기, 탭 부착을 진행합니다. 국소 다듬기는 특정 접합 후보 주변에만 적용되고 최종 외곽 전체에 R1을 보장하지 않습니다.

탭 폭은 사용자가 설정한 값(기본 30mm)을 그대로 유지합니다. 탭이 스캐폴드의 둥글린 외형 폭보다 넓으면 화면과 검사 상태에 경고하며 자동으로 축소하지 않습니다. 후보 생성은 약 300dpi 래스터 격자를 사용하므로 픽셀 단위 치수 오차가 있습니다. 최종 칼선의 치수는 본품, 조각 선별, 후처리 및 탭에 따라 달라질 수 있으므로 실제 출력 전 확인하세요.

기본 설정은 탭을 포함한 목표 높이 148.5 mm이며 실제 편집 결과는 화면의 크기 및 연결 상태를 확인하세요. 이 도구는 재료 강도를 인증하지 않으므로 시제품 검증이 필요합니다. 세션은 브라우저 메모리에만 남습니다.
